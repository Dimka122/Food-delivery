# 🍕 Ресторан Food Delivery

# 🍕 Админ Панель для Food Delivery

Современная и функциональная административная панель для ресторана "Food Delivery", созданная на базе Next.js 16, React 19, TypeScript и Tailwind CSS.

## 🚀 Возможности админки

### 📊 **Дашборд**
- Общая статистика ресторана
- Графики продаж и заказов
- Популярные товары и категории
- Последние заказы в реальном времени
- Статистика по клиентам

### 📦 **Управление товарами**
- **CRUD операции**: добавление, редактирование, удаление товаров
- **Категоризация**: привязка товаров к категориям
- **Статусы**: управление доступностью товаров
- **Хиты продаж**: отметка популярных товаров
- **Поиск и фильтрация** по названию и категории

### 🛒 **Управление заказами**
- **Просмотр всех заказов** с детальной информацией
- **Изменение статусов**: ожидание → подтверждение → приготовление → готов → доставляется → доставлен
- **Фильтрация по статусам** и поиск по клиентам
- **Детальный просмотр** каждого заказа
- **Контактная информация** клиентов и адреса доставки

### 🏷️ **Управление категориями**
- **Создание и редактирование** категорий товаров
- **Эмодзи-иконки** для категорий
- **Активация/деактивация** категорий
- **Статистика** по количеству товаров и заказов

### 📈 **Аналитика**
- **Продажи по дням** с графиками
- **Распределение по категориям** (круговые диаграммы)
- **Топ товары** по популярности и доходности
- **Анализ клиентов**: новые vs возвращающиеся
- **Почасовые продажи** для оптимизации работы

### ⚙️ **Настройки**
- **Информация о ресторане**: название, описание, контакты
- **Часы работы** для будних и выходных дней
- **Настройки доставки**: стоимость, время, бесплатная доставка
- **Способы оплаты**: наличные, карта курьеру, онлайн
- **Уведомления**: настройка алертов и каналов связи
- **Внешний вид**: цветовая схема и тема

## 📱 Функциональность

### Управление товарами
```typescript
interface FoodItem {
  id: number
  name: string
  description: string
  price: number
  image: string
  category: string
  rating: number
  isPopular?: boolean
  isAvailable?: boolean
}
```

### Управление заказами
```typescript
interface Order {
  id: string
  customerName: string
  customerPhone: string
  address: Address
  items: OrderItem[]
  total: number
  status: OrderStatus
  createdAt: string
}
```

### Статусы заказов
- `pending` - Ожидает подтверждения
- `confirmed` - Подтвержден
- `preparing` - Готовится
- `ready` - Готов к выдаче
- `delivering` - Доставляется
- `delivered` - Доставлен
- `cancelled` - Отменен

## 🔧 Настройка и развертывание

### Переменные окружения
```env
NEXT_PUBLIC_API_URL=http://localhost:3000/api
JWT_SECRET=your-jwt-secret
RESEND_API_KEY=your-resend-api-key
ORDER_EMAIL=orders@vkycdoctavka.com
```

### Запуск проекта
```bash
npm install
npm run dev
```

### Сборка для продакшена
```bash
npm run build
npm start
```
